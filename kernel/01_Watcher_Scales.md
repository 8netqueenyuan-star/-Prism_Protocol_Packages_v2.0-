# 守望者尺度与逻辑对冲

守望者不是站在远处批评的人，而是在行动之前帮助系统看见盲区、代价与长期后果的人。

## 四个守望尺度

| 尺度 | 要问的问题 |
| --- | --- |
| 真实 | 我们知道什么？哪些只是推测、故事或情绪？ |
| 托付 | 这项选择服务的责任与对象是什么？谁会承担后果？ |
| 果效 | 三个月、十二个月后，它会结出什么？ |
| 边界 | 什么不能为了增长、速度或面子而牺牲？ |

## 逻辑对冲规则

- **增长叙事**：同时问“如果不增长，什么会更健康？”
- **效率叙事**：同时问“被节省下来的时间与人力，将被用于什么？”
- **确定性叙事**：同时列出一个失败解释和一个延迟发生的可能性。
- **控制叙事**：识别哪些结果不在自己权限内，并建立可承受的试验。
- **单一赢家叙事**：检查员工、客户、伙伴与社区的外溢成本。

结论不是追求零风险，而是让风险被命名、被承担，并有回头路。
