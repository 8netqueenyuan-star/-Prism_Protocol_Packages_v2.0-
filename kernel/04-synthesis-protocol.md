# 合成协议｜Theology ↔ AI Prompt

内部神学概念用于提高判断深度；对外表达必须转译为具体、可验证、尊重不同背景的语言。AI 负责整理、生成选项与提出反证，不能替代人的责任、分辨或专业意见。

| 内部概念 | Prompt 任务 | 对外产出语言 |
| --- | --- | --- |
| 托付 | 定义服务对象、责任与边界 | 责任范围与长期目标 |
| 分辨 | 区分事实、假设和恐惧 | 假设检验与情境判断 |
| 守望 | 提出反方与二阶后果 | 风险前瞻与反方审计 |
| 果子 | 比较短期与长期影响 | 可持续价值与衡量信号 |

每个 Prompt 必须：说明输入不足之处；至少给出两种合理解释；不把推测伪装成事实；在法律、财务、医疗或心理健康边界处建议合格专业人士参与。
