# Entitlement Model

## 1. 权利的定义

Entitlement 指购买或加入后，客户实际获得的具象权利与责任边界。它不是“是否能打开某个文件”，而是：

- 是否拥有访问权；
- 是否可以下载；
- 是否能使用产品；
- 是否能进行适配；
- 是否能交付给客户；
- 是否能将其用于团队或组织；
- 是否拥有更新权和续费权；
- 何时到期、如何更新、如何续订；
- 该产品属于哪个版本与许可范围。

---

## 2. 基础权利结构

| 权利模块 | 说明 | 适用对象 |
| --- | --- | --- |
| Access | 访问产品目录、内容与说明文档 | 全部会员 |
| Download | 下载模板、工作流、案例或适配器 | 视许可 |
| Updates | 获取新版本、修订和更新说明 | 视会员/产品 |
| Membership Benefits | 会员资格、持续内容更新和支持 | 会员 |
| License Scope | 使用、适配、共享和交付范围 | 视协议 |
| Expiration | 到期与失效时间 | 视购买/许可 |
| Renewal | 续期与续费条件 | 会员与机构 |
| Product Version | 当前版本数、升级状态和兼容性 | 全部产品 |
| Partner Products | 第三方产品的授权范围与收益规则 | Partner |

---

## 3. 权利层次

### 3.1 Access

允许：
- 浏览产品目录；
- 查看说明和方法；
- 访问基础内容；
- 进入会员专区。 

限制：
- 仅限授权范围；
- 不等于可复制、可再分发或可商业化。

### 3.2 Download

允许：
- 下载产品包、模板与工作流；
- 复制到个人或授权团队环境中使用。

限制：
- 受许可范围和版本绑定限制；
- 不包括 Kernel 或未授权的核心定义内容；
- 不得脱离协议再分发。

### 3.3 Updates

允许：
- 获取修订说明；
- 获取产品版本更新；
- 进行兼容性更新和维护。

限制：
- 重大版本更新需按协议更新授权；
- 过期版本可保留归档，但不再视为有效使用。

### 3.4 Membership Benefits

允许：
- 访问平台内容；
- 使用增强功能；
- 持续更新；
- 享受固定的支持与复盘节奏。

限制：
- 不同会员级别具有不同权益；
- 会员资格到期后，部分权益会自动失效。

### 3.5 License Scope

定义：
- 个人还是团队；
- 是否允许适配；
- 是否允许交付给客户；
- 是否允许内部多用户共享；
- 是否允许衍生产品。

要求：
- 所有权限必须是显式声明，不允许默认无限制授权。

### 3.6 Expiration and Renewal

- 所有非永久性权利必须有到期日期；
- 过期后，使用权、交付权和更新权自动收回；
- 续约必须遵循当时有效的协议和版本状态；
- Institutional 方案可设置多期或年续约机制。

### 3.7 Product Version

每个产品的 entitlements 都必须明确：
- 当前版本；
- 兼容版本；
- 是否可升级；
- 是否支持历史版本；
- 是否允许回滚。

### 3.8 Partner Products

对 Partner 产品的义务与权限：

- 由认证商品才有资格进入合作目录；
- 允许在授权范围内访问和使用；
- 允许在协议内交付服务；
- 收益分成和更新责任由协议规定；
- 不得覆盖 Prism Kernel 的保留权利。

## 4. 权利矩阵

本矩阵定义每个会员等级实际获得的权利状态。会员等级定义见 membership.md。

| 权利 | Individual | Professional | Enterprise | Partner |
| --- | --- | --- | --- | --- |
| Access | 是 | 是 | 是 | 是 |

| Updates | 是 | 是 | 是 | 是 |
| Membership Benefits | 是 | 是 | 是 | 是 |
| Team Use | 否 | 是 | 是 | 视协议 |
| Internal Adaptation | 限制 | 是 | 是 | 是 |
| External Delivery | 否 | 限制 | 是 | 是 |
| Revenue Share | 否 | 否 | 视协议 | 是 |
| Product Development | 否 | 否 | 视协议 | 是 |
| Governance Rights | 否 | 否 | 是 | 视协议 |

---

## 5. 重要规则

1. 访问权不能被误解成永久所有权；
2. 产品使用权必须绑定许可范围；
3. 组织与 Partner 的公开传播需要协议；
4. 到期后，所有更新、下载和交付权必须停止，除非完成续期；
5. 任何产品都必须保留更新说明、版本记录和责任归属；
6. 不允许无边界使用 Prism Kernel 或关键定义内容。

---

## 6. 适用边界

本文件定义的是 Prism 的数字产品权利结构，不构成正式法律合同。所有客户购买、会员升级、产品授权和收益共享都必须以正式协议为准。
