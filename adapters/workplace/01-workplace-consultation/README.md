# 职场会诊提示词 · Workplace Consultation Prompt

> 体系归属：Watchers Cognitive OS · `adapters/workplace` · workplace-01
> 版本：v1.0.0（2026-10-17）｜ Full SKU · Ko-fi $29（买断）

## 一句话

一套可复制进任意 AI 的职场会诊系统——不替你看透人心，而是帮你把"已知的、你在解释的、还没证实的"分开，形成、检验并修正自己的判断。

## 产品定位

面向在职场关键处境中需要做判断的人：饭局冷遇、汇报述职、晋升竞争、同事冲突、领导 PUA、合伙人散伙。它提供的不是一次"被看透"的结论，而是一套可重复使用的判断流程。

## 工作流程

1. **选择情境（可选）**：在 6 个情境包中选择最贴近的，补充关键信息；没有合适情境可直接描述问题。
2. **跑提示词**：复制完整提示词给 AI，开头加一句"本次场景=X，角色=X，诊断重点=X"，贴入案例。
3. **做复盘**：用复盘工具把判断固定成可追踪、可修正的记录。
