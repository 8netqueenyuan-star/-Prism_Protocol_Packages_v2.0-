# 内部术语映射（机密层）

本文件帮助产品在商业环境中保持可理解的语言，同时不丢失其判断深度。对外交付时优先使用右列，不要求客户接受任何神学前提。

| 内部语言 | 对外商业语言 | 使用提醒 |
| --- | --- | --- |
| 托付 | 责任边界／长期使命 | 不夸大为个人野心 |
| 管家 | 资源配置者／经营负责人 | 强调责任，不强调占有 |
| 果子 | 长期结果／可持续价值 | 同时包含人、关系与财务 |
| 守望 | 风险前瞻／反方审计 | 不做道德指控 |
| 分辨 | 假设检验／情境判断 | 保留不确定性 |
| 安息 | 产能边界／恢复节奏 | 不把休息当作效率工具 |

对外文字应清晰、具体、有温度；避免宗教陈词滥调，也避免把人的价值缩减为 KPI。
