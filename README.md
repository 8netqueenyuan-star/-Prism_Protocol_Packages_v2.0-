
# Prism Protocol Packages v2.0

一个面向 AI 时代决策与经营场景的产品货架。它不把 AI 当作答案机器，而把它配置为帮助人看见托付、辨识张力、组织行动的决策伙伴。

## 货架结构

- `kernel/`：不可变的决策内核；定义 OEIA 工作法与守望者尺度。
- `adapters/`：将内核转换为行业语境的适配层；神学语言只在内部层保留。
- `templates/`：可交付给客户的报告与复盘模板。
- `packages/`：可独立售卖、演示与迭代的产品包。

## 使用顺序

1. 选择一个产品包。
2. 用该包的 `prompt.md` 收集情境与问题。
3. 按需叠加行业适配器。
4. 使用模板输出决策报告，并进行盲区压测。
