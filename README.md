
# Prism Protocol Packages v2.0｜AI 超市货架

一个面向 AI 时代决策与经营场景的产品货架。它不把 AI 当作答案机器，而把它配置为帮助人看见托付、辨识张力、组织行动的决策伙伴。

> 卖的不是单个 AI 工具，而是「神学决策框架的 AI 化封装」：让意义、能力、场景、交付与持续更新成为可复制的产品系统。

## 货架结构

- `kernel/`：棱镜内核；定义 OEIA 工作法、守望尺度与合成公式。
- `packages/`：产品货架；每个 SKU 都是「意义 × AI 能力」的合成单元。
- `adapters/`：场景适配器；把产品插入事工、商业、教育与家庭管家语境。
- `templates/`：即插即用的提示词、工作流与交付模板。
- `ops/`：货架运营；定义上架、更新和本地合伙人复制机制。

**产品生成链路：** Meaning → Capability → Context → Delivery → Scale（意义 → 能力 → 场景 → 交付 → 规模）。

## 内核兼容说明

现有 `00_OEIA_Core_Protocol.md` 与 `01_Watcher_Scales.md` 是不可替代的原始决策内核。新增的 `01`–`04` 文件是面向产品设计的棱镜透镜，并不取代原内核。第一款产品沿用已有目录 `packages/01-decision-compass-universal/`，以保持旧链接及已有客户材料可用；它即是 v2.0 中的「决策罗盘」参考产品。

## 使用顺序

1. 选择一个产品包，并阅读其 `theology-card.md`（内部定义层）。
2. 使用 AI 能力包收集情境与问题，再选择匹配的场景适配器。
3. 按工作流执行，交付模板化结果。
4. 使用反思清单作盲区压测，并按更新协议复盘。
